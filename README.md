# Strydex Community Portal

A high-performance, cybernetic engineering portal for AI-powered exoskeleton robotics. Replicated pixel-by-pixel with interactive 3D WebGL CAD models, real-time audio synthesis, task boards, and content library tracks.

---

## 🚀 Quick Start (Run Locally)

### Prerequisites
- [Node.js](https://nodejs.org/) (version 18 or higher recommended)

---

### Step 1: Install Dependencies
Open your terminal inside this project folder and run:

```bash
npm install
```

---

### Step 2: Start the Development Server

```bash
npm run dev
```

The portal will be hosted locally at:
👉 **http://localhost:5173/**

---

## ⚡ 1-Click Launch (Windows)
Double-click `start.bat` in this folder. It will automatically install any missing dependencies and open the portal in your default browser.

---

## 📁 Available Screens & Views
- **Dashboard Hub**: `http://localhost:5173/#dashboard`
- **Live AMA & 3D CAD Orbit**: `http://localhost:5173/#sessions`
- **Content Library (4 Tracks)**: `http://localhost:5173/#content-library`
- **Task Board & Subassemblies**: `http://localhost:5173/#task-board`
- **Milestones & Skill Matrix**: `http://localhost:5173/#progress`
- **Session Archive**: `http://localhost:5173/#session-archive`
- **Access Code Verification**: `http://localhost:5173/#access-code`

## 🛠️ Tech Stack
- **React 19** + **Vite 6**
- **Tailwind CSS v4**
- **Three.js** (Interactive 3D WebGL Manifold CAD Viewer)
- **Web Audio API** (Synthesized cybernetic audio feedback)
- **Canvas Confetti** (Milestone rewards & achievements)
- **Lucide Icons**
